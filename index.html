01

PRODUCT

From monitoring to action.

Pavu aims to monitor application behavior, identify risk, notify you, and help you respond. Here is what the macOS prototype can do today—and what still needs to be built.

01

Monitor · available

The macOS prototype collects real TCP/UDP network metadata and shows activity by application. File events require Apple's Endpoint Security entitlement and user permission.

02

Identify · available

Local rules flag patterns such as large outbound transfers, periodic connections, unusual ports, and suspicious executables. Missing evidence is shown, and dependent rules are skipped.

03

Notify · in-app only

Findings and supporting evidence appear in the app. Proactive system notifications are not implemented yet.

04

Mitigate · guidance only

Pavu offers response recommendations. Reversible connection blocking remains planned; every connection is currently allowed.

02

PRIVACY

Useful context, without reading your content.

PAVU OBSERVES

  • Application and process identity
  • Destination domain (when available), IP, port, and protocol
  • Connection timing, direction, state, and reported byte counts
  • File-operation metadata when separately authorized

PAVU NEVER COLLECTS

  • Network payloads or TLS plaintext
  • Passwords, cookies, authentication tokens, or message contents
  • File contents
  • Keyboard, screen, camera, or microphone content

Activity metadata stays on the Mac and is retained for the most recent 24 hours by default. You can pause monitoring or clear stored data. Cleanup of expired records waits while the app is closed or the Mac is asleep.

Optional IP-location lookup is off at every launch. If you enable it, public destination IPs are sent to ipapi.co; application identities, file paths, and activity records are not sent. Local detection does not need this lookup.

03

ARCHITECTURE

Designed around a local trust boundary.

1

System collectors

On macOS, a Network Content Filter extension collects flow metadata. File-event collection is only a skeleton until Apple grants the Endpoint Security entitlement and the user authorizes it.

→
2

Pavu Core

The shared Rust core normalizes observations, builds basic baselines, correlates behavior, evaluates local rules, and stores recent activity in SQLite.

→
3

Explainable interface

The macOS SwiftUI app shows per-application activity, local findings, history, and response guidance. File activity appears only when collection is authorized and available.

04

OPEN SOURCE

A shared core. Clear platform status.

Pavu is being developed as an open-source project under Apache License 2.0. Public access to the product source is being prepared. The macOS prototype uses the shared Rust core today; other platforms have no usable release.

macOS Buildable prototype · macOS 14+

Real TCP/UDP metadata, application activity views, local findings, and history. Testing needs Xcode, Rust, signing, and system-extension approval.

Linux Unavailable to users

An observe-only eBPF-to-Core engineering prototype exists, but there is no usable Linux product.

Windows Unavailable to users

Interfaces and directories are reserved; the Windows collector and client are not implemented.

Android Unavailable to users

A future platform direction; there is no usable Android product.
