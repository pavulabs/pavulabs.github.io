PRODUCT

Security signals that make sense.

Pavu turns isolated events into an evidence chain: which app acted, what it touched, where it connected, and why the combination may be risky.

01

Application-aware

Attribute connections to the responsible application, bundle identity, process, and executable path when macOS makes them available.

02

Behavior correlation

Connect network flows with file and process metadata to detect patterns that a connection list alone cannot explain.

03

Explainable findings

Every finding includes a severity, concise reason, supporting evidence, related activity, and a recommended response.

02

PRIVACY

Useful context, without reading your content.

PAVU OBSERVES

  • Application and process identity
  • Destination host, IP, port, and protocol
  • Connection timing, direction, state, and byte counts
  • File-operation metadata when separately authorized

PAVU NEVER COLLECTS

  • Network payloads or TLS plaintext
  • Passwords, cookies, or message contents
  • Complete file contents
  • Cloud telemetry in the current product

Metadata stays on the Mac and is retained for 24 hours by default. Monitoring can be paused and stored data can be cleared at any time.

OPEN SOURCE

Open code. Shared core. Platform-native protection.

Pavu is an open-source project licensed under Apache License 2.0. Its shared Rust core keeps detection and data semantics consistent, while native adapters integrate with each operating system's supported security interfaces. Public source access is being prepared.

macOS Private beta

Network Extension collector and native SwiftUI application.

CURRENT STATUS

Built for careful real-world validation.

Pavu for macOS is currently in private beta, the Linux collector is an early prototype, and the Windows adapter is planned. macOS network collection uses Apple-supported system extension APIs and observes without blocking. File-activity collection remains disabled in public builds until Apple grants the Endpoint Security entitlement.
