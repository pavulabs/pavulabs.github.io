PRIVACY

Understand behavior without reading content.

PAVU OBSERVES

  • Which app connects to which destination
  • When it connects and how much data it sends
  • File activity, only when access is available and approved

PAVU NEVER COLLECTS

  • The contents of your files or messages
  • Passwords, cookies, or sign-in tokens
  • Network traffic contents

Activity history stays on your Mac and is normally kept for one day. You can pause monitoring or clear it.

Optional location lookup is off by default. If you turn it on, Pavu sends public destination IP addresses to ipapi.co, but not app names or file paths.
